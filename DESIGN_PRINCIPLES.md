# Design principles

1. Calm before cleverness — reduce noise and avoid unnecessary urgency.
2. One clear next step — every screen should make the next action legible.
3. Respect attention — default to fewer, better choices.
4. Local-first trust — make core behavior useful without a network connection.
5. Honest progress — never manufacture momentum with badges or empty counts.
6. Soft edges, strong structure — visual warmth should not reduce clarity.
